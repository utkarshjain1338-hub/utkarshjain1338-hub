## About

I'm a 19-year-old builder from India. After a year of BTech in Computer Science, I stepped away from the traditional track to prepare for the **IIT Madras BS in Data Science & Applications** — betting on depth over a degree checkbox.

- 🎯 **Right now** — building [PactFlow](#featured-projects), a secure escrow platform, and preparing for the IIT Madras qualifier
- 📚 **Learning** — Java & OOP fundamentals, daily DSA, Spring Boot, PostgreSQL
- 🔌 **Also tinkering with** — ESP32 / embedded electronics, and a personal speech-to-text & text-to-speech pipeline
- 🏆 **Hackathons** — Orange Belt winner for a Stellar Soroban NFT-leasing project
- 🌱 **Side quest** — learning Japanese (N5) and making Linux/dev content

I learn by shipping — real backends, real hardware, real deadlines, not tutorials.
